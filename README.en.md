# Atlas Hydro

[Version française](README.md)

In Quebec, electricity production is managed by Hydro-Québec. As a state-owned enterprise, it provides a wealth of datasets concerning its facilities, hydroelectric production, electricity imports and exports, and much more!

Atlas Hydro is an interactive map showcasing Hydro-Québec's facilities throughout Quebec. Various data points for each facility can also be accessed on the site. Beyond the infrastructure, Atlas Hydro allows users to visualize other data, such as electricity production, exports, and consumption across Quebec.
